# 猪哥哥保险场景营销 (Zhugege Insurance Scene Marketing)

> 基于九宫格场景拓展法的保险场景营销专用引擎。拒绝生硬条款与道德绑架，让真实生活细节成为痛点主角，让保险像影子一样低调融入。

---

## 💡 核心设计理念：1 + 4 黄金法则

客户反感的从来不是保险，而是“喋喋不休推销条款的业务员”。

本 Skill 专为**家庭财务风险、健康大病风险、顶梁柱现金流断流风险与突发意外风险**而生：

1. **输入极简**：只需提供客户的【职业年龄】、【家庭结构】、【资产负债】与【核心焦虑】4 项要素。
2. **1 张全景关系矩阵罗盘**：8 对核心社会关系 $\times$ 8 个生活高压场景。
3. **4 大核心风险象限高光画面**：
   - 🎬 **画面 1（健康风险）**：大病与自费药抉择（映射百万医疗/特药）
   - 🎬 **画面 2（财务风险）**：顶梁柱现金流断流（映射定期寿险/收入损失）
   - 🎬 **画面 3（夹心层风险）**：养老看护与刚性责任挤压（映射终身寿/防癌/养老金）
   - 🎬 **画面 4（意外风险）**：突发黑天鹅与紧急流动性（映射综合意外/应急金）
4. **影子般低调的提示（Shadow Anchor）**：结尾不提任何产品名字，只用一句电影旁白般的白字，点出痛点本可以被几百块默默化解。
